10. List methods jo zaroor yaad hone chahiye

| Method      | Kaam                      |
| ----------- | ------------------------- |
| `append()`  | End mein item add         |
| `insert()`  | Specific position par add |
| `extend()`  | Multiple items add        |
| `remove()`  | Value remove              |
| `pop()`     | Index se remove           |
| `clear()`   | List empty                |
| `sort()`    | Sort                      |
| `reverse()` | Reverse                   |
| `count()`   | Occurrences count         |
| `index()`   | Item ka index find        |
| `copy()`    | List ki copy              |
